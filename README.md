# Linux Ansible Lab

Hands-on Linux system administration and Ansible automation lab using RHEL and Ubuntu virtual machines.

## Environment

- RHEL - Ansible control node
- Ubuntu - Managed server
- VirtualBox
- SSH
- Ansible Core 2.16.16
